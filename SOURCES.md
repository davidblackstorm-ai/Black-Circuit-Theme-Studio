OFFICIAL-SOURCES.json and app/official-manifest.js map each of the 27 preview entries to its exact original image, page URL or PDF page. Official UI imagery and Ableton marks belong to Ableton. They are used here as requested reference material; this independent editor is not an official Ableton application. Original-color mode displays the original images; palette simulation preserves image geometry but approximates colors.

Live 10 XML schema reference: https://github.com/amydevs/AbletonLiveThemeConverter/blob/master/test_themes/blank_10.ask (MIT, copyright 2024 Amy!). License: app/ALTCONVERTER-LICENSE.txt. Live 11 and 12 schema references come from original .ask files in the local installations.

LiveThemes was consulted as an editor interaction reference; no service connection or website code is included. Black Circuit logo: original local vector/canvas design. The installer contains no music.
